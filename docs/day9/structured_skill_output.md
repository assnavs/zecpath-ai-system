# Structured Skill Output

## Purpose

The Skill Extraction Engine converts unstructured resume text into structured skill information suitable for ATS processing.

---

## Output Structure

Each extracted skill contains:

- Skill Name
- Skill Category
- Confidence Score

Example:

```json
{
    "skill": "Python",
    "category": "Programming",
    "confidence": 1.0
}
```
