# ATS Scoring Engine

## Overview

The ATS (Applicant Tracking System) Scoring Engine is the core evaluation component of the Zecpath AI ATS Resume Screening System. Its primary responsibility is to calculate an overall candidate score by combining multiple evaluation parameters into a single transparent and explainable result.

Unlike traditional ATS systems that rely only on keyword matching, this scoring engine considers several candidate attributes, including skills, experience, education, and semantic similarity, to generate a balanced assessment. The engine is designed to be configurable, reusable, and easy to extend for different recruitment scenarios.

---

# Objective

The objective of the ATS Scoring Engine is to provide a standardized scoring mechanism that evaluates candidates based on predefined criteria while maintaining transparency in how the final score is calculated.

The engine should:

- Calculate an overall ATS score.
- Support multiple evaluation parameters.
- Produce explainable scoring results.
- Work with configurable weights.
- Handle incomplete resume data safely.

---

# Evaluation Parameters

The scoring engine evaluates candidates using the following parameters:

## 1. Skill Match

Measures how well the candidate's skills match the required job skills.

Examples include:

- Programming Languages
- Frameworks
- Libraries
- Technical Skills
- Tools

---

## 2. Experience Relevance

Evaluates how closely the candidate's work experience aligns with the target job role.

Factors considered include:

- Years of experience
- Relevant job roles
- Domain expertise
- Industry relevance

---

## 3. Education Alignment

Determines whether the candidate's educational qualifications satisfy the job requirements.

Examples:

- Degree relevance
- Educational level
- Academic specialization

---

## 4. Semantic Similarity

Uses semantic embeddings generated by the Semantic Matching Engine to compare the overall meaning of the resume against the job description.

Unlike keyword matching, semantic similarity identifies contextual relationships between candidate qualifications and employer requirements.

---

# ATS Scoring Workflow

The ATS Scoring Engine follows the workflow below:

1. Receive candidate evaluation scores from previous ATS modules.
2. Retrieve the appropriate weight configuration based on the selected job role.
3. Calculate weighted scores for each evaluation parameter.
4. Compute the overall ATS score.
5. Generate an explainable score breakdown.
6. Produce a hiring recommendation.

---

# Scoring Formula

The overall ATS score is calculated using a weighted average.

Overall Score =

(Skill Match × Weight)

+

(Experience Relevance × Weight)

+

(Education Alignment × Weight)

+

(Semantic Similarity × Weight)

The weights are loaded dynamically from the configuration file, allowing different job roles to have different scoring priorities.

---

# Recommendation Logic

Based on the calculated ATS score, the engine classifies candidates into recommendation categories.

| Score | Recommendation |
|--------|----------------|
| 90–100 | Excellent Candidate |
| 80–89 | Strong Candidate |
| 70–79 | Good Candidate |
| 60–69 | Average Candidate |
| Below 60 | Needs Improvement |

---

# Missing Data Handling

The ATS Scoring Engine is designed to handle incomplete resume information gracefully.

If any evaluation parameter is unavailable:

- Skill Match defaults to 0.
- Experience Relevance defaults to 0.
- Education Alignment defaults to 0.
- Semantic Similarity defaults to 0.

This prevents runtime errors while still generating a valid ATS score.
