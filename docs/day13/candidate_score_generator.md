# Candidate Score Generator

## Overview

The Candidate Score Generator is the final component of the ATS Scoring Framework responsible for producing the overall ATS score for a candidate. It combines the results from various resume evaluation modules, applies the role-specific weight configuration, and generates a transparent score along with an explainable recommendation.

This module acts as the final decision-making layer of the ATS Resume Screening System by transforming multiple evaluation metrics into a single, meaningful candidate score.

---

# Objective

The primary objective of the Candidate Score Generator is to calculate a standardized candidate score that accurately reflects the suitability of a candidate for a specific job role.

The module is designed to:

- Combine multiple evaluation parameters.
- Apply job role-specific weight configuration.
- Generate an overall ATS score.
- Produce an explainable score breakdown.
- Provide a hiring recommendation.
- Handle incomplete candidate information gracefully.

---

# Input Parameters

The Candidate Score Generator receives evaluation results from previously implemented ATS modules.

## Skill Match

Represents how closely the candidate's technical skills match the required job skills.

Example:

- Python
- SQL
- Machine Learning
- Data Analysis

---

## Experience Relevance

Represents the relevance of the candidate's previous work experience to the selected job role.

Factors considered include:

- Relevant job titles
- Industry experience
- Years of experience
- Domain expertise

---

## Education Alignment

Represents how well the candidate's educational qualifications align with the job requirements.

Examples include:

- Degree level
- Field of study
- Academic specialization

---

## Semantic Similarity

Represents the contextual similarity score generated by the Semantic Matching Engine.

Unlike traditional keyword matching, semantic similarity evaluates the meaning of resume content and compares it with the job description.

---

# Score Generation Process

The Candidate Score Generator follows a structured workflow.

### Step 1

Receive candidate evaluation scores from previous ATS modules.

↓

### Step 2

Receive the selected job role.

↓

### Step 3

Load the corresponding weight configuration from the JSON configuration file.

↓

### Step 4

Calculate weighted scores for each evaluation parameter.

↓

### Step 5

Compute the final ATS score.

↓

### Step 6

Generate the recommendation category.

↓

### Step 7

Return the structured scoring output.

---

# Recommendation Categories

The final ATS score is mapped to predefined recommendation levels.

| ATS Score | Recommendation |
|-----------|----------------|
| 90 – 100 | Excellent Candidate |
| 80 – 89 | Strong Candidate |
| 70 – 79 | Good Candidate |
| 60 – 69 | Average Candidate |
| Below 60 | Needs Improvement |

These recommendation levels help recruiters quickly identify the most suitable candidates.


Evaluation Scores

| Parameter | Score |

| Parameter | Weight |

Overall Score

```
(90 × 0.40)
+
(80 × 0.20)
+
(75 × 0.10)

(85 × 0.30)

85.0
```

Recommendation

```
Strong Candidate
```
