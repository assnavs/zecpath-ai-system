## Stakeholder Q&A rehearsal

**Q: Does the system make the final hiring decision?**  
A: No. It generates a structured recommendation for an authorized human reviewer. Human review remains mandatory.

**Q: Are all scores generated by machine-learning models?**  
A: No. The current implementation includes rule-based and rubric-based components. The exact method varies by module.

**Q: Does the demo process a real uploaded resume end to end?**  
A: The simulator uses supplied structured inputs. The API upload route stores the uploaded file and creates a demonstration job record; the repository documentation identifies the parser integration boundary. The synthetic demo does not prove a complete production upload-to-decision workflow.

**Q: How are scores combined?**  
A: A role-specific weighted average is calculated across available rounds. Missing rounds are excluded and the remaining weights are renormalized. Coverage is reported separately.

**Q: Is the confidence score a probability?**  
A: No. It is a coverage-based heuristic and should not be interpreted as statistical confidence.

**Q: Does the machine test execute candidate code?**  
A: No. The current machine-test component evaluates supplied test outcomes and rubric fields; it does not execute untrusted candidate code.

**Q: What happens when a round is missing?**  
A: The aggregation output identifies missing rounds, reports reduced coverage and renormalizes the weights of the available rounds. Recommendation logic can hold a candidate for insufficient coverage.

**Q: Is the platform production-ready?**  
A: This is an internship prototype. The current API uses in-memory stores and the observability/audit utilities are in-process. Production deployment would require persistent storage, authentication/authorization, secure file handling, queue infrastructure, monitoring, privacy review and operational validation.

**Q: What is the business value?**  
A: The prototype aims to structure evidence and make review more consistent. Quantified time savings, accuracy gains or hiring-quality improvements have not been measured.
